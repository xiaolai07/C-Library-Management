# C语言控制台图书馆管理系统

> 控制台版图书管理系统，C语言实现，链表完成内存操作，txt文件做数据持久化。

## 项目简介
本项目是课程设计作业，基于C语言开发，Windows控制台运行。
数据保存在 `library.txt`，不需要数据库。
功能包含：
- 新增图书信息
- 删除图书（按书名删除）
- 修改图书信息
- 图书浏览：直接浏览、书号升序、书号降序
- 图书查询：支持书号 / 书名 / 作者 / 类别检索
- 统计图书总数量

## 开发环境
- Windows
- Visual Studio 2019 / 2022
- C语言标准 C89 / C99
> 依赖头文件：`conio.h`、`windows system函数`，**仅支持Windows平台，Linux/macOS无法直接编译**

## 运行说明
1. 将源码导入Visual Studio空项目
2. 编译运行，程序自动生成 `library.txt` 文件保存图书数据
3. 文件生成位置：项目输出目录 `x64/Debug/`
